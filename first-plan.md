# Поэтапный план NORMWEAR (все фазы)

## Фаза 0. Каркас — ✅ готово
venv, зависимости (aiogram 3.22, fastapi, sqlalchemy, aiosqlite/asyncpg, httpx, pydantic-settings), `.env`+`.env.example`, структура `app/` с модулями ≤300 строк.
Критерий: `python -m app.main --check` без ошибок.

## Фаза 1. БД-схема — ✅ готово
20 таблиц: users, addresses, brands, categories, products, product_photos, cart_items, orders, order_items, order_status_history, payments, referrals, loyalty_transactions, promo_codes, promo_redemptions, support_tickets, support_messages, admin_audit, channel_posts. Dev=SQLite, prod=PostgreSQL (конверсия URL в config.db_url).
Критерий: create_all проходит, seed категорий/брендов работает.

## Фаза 2. Шоп-бот — ✅ готово
/start, меню (каталог/корзина/заказы/бонусы/поддержка), каталог по брендам с пагинацией, карточка с выбором размера, корзина, Checkout FSM (имя→телефон→город→адрес→промо/бонусы→подтверждение), «Мои заказы», бонусы и реферальная ссылка, тикеты поддержки.
Критерий: заказ создаётся, админы получают уведомление.

## Фаза 3. Админ-бот — ✅ готово
Пересылка постов `@optobaza` (media_group buffering + debounce), парсинг, карточка модерации (опубликовать/цена/режим фото/отклонить), публикация в канал, заказы со сменой статусов и треками, промокоды, статистика, ответы на тикеты.
Критерий: пересылка → публикация в канал за один клик.

## Фаза 4. Фото — ✅ готово
Комбинированный подбор: file_id из поста поставщика + пути Яндекс.Диска по бренду (публичный ключ, download API, кэш href).
Критерий: публикация с медиагруппой до 10 фото.

## Фаза 5. Заказы — ✅ готово
`awaiting_delivery → awaiting_payment → shipped → delivered → completed` (+cancelled), автоматические уведомления клиенту, история статусов.
Критерий: смена статуса шлёт клиенту текст по шаблону.

## Фаза 6. Доп. фичи — ✅ готово
Бонусы (1% кэшбэк при завершении, списание до 30%), рефералка (+100), промокоды (проценты, мин. сумма, лимит), поддержка с тикетами.
Критерий: логика покрыта в `app/services/orders.py`.

## Фаза 7. Мини-апп — ✅ готово (упрощённо)
Одностраничный WebApp (Telegram WebApp SDK): бренды-чипы, сетка товаров, размер, POST /api/cart, deeplink на оформление в боте. React+Vite — при росте требований.
Критерий: каталог открывается, корзина синхронизируется с ботом.

## Фаза 8. Деплой — ✅ конфиги готовы
Dockerfile, render.yaml (web + free Postgres), start.bat для Windows.
Критерий: Render поднимает сервис, боты работают по polling.

## Фаза 9 (потом). Автопарсинг поставщика
Telethon-клиент по `SUPPLIER_SESSION_STRING`: авто-парсинг новых постов `@optobaza` → черновики в админке. Требует API_ID/API_HASH.
Критерий: новый пост канала появляется в админ-боте без пересылки.

## Фаза 10 (потом). Платежи
Интеграция TELEGRAM_PAYMENT_PROVIDER_TOKEN / СБП: счета и авто-подтверждение оплаты.
Критерий: оплата в боте переводит заказ в следующий статус автоматически.
