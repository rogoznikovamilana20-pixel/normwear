## Что нужно сделать для запуска 🚀

### 1. Деплой на Render (30 минут)

1. **Создай аккаунт на Render**
   - Перейди на https://render.com
   - Зарегистрируйся через GitHub

2. **Подключи репозиторий**
   - New + → Blueprint
   - Выбери `rogoznikovamilana20-pixel/normwear`
   - Нажми Apply

3. **Настрой переменные окружения**
   В Environment Variables добавь:
   ```
   SHOP_BOT_TOKEN = твой_токен_магазин_бота
   ADMIN_BOT_TOKEN = твой_токен_админ_бота
   SHOP_CHANNEL_ID = -1004387729213
   ADMIN_TELEGRAM_IDS = 1977604257
   SHOP_CHANNEL_USERNAME = normwear_shop
   SHOP_USERNAME = norm_shop_bot
   ```

4. **Запусти деплой**
   - Manual Deploy → Clear build cache & deploy
   - Жди 3-5 минут

5. **Проверь работу**
   - Открой URL приложения
   - Проверь `/healthz` → `{"ok":true}`
   - Протестируй бота

### 2. Настрой мониторинг (5 минут)

1. **UptimeRobot**
   - Зарегистрируйся на https://uptimerobot.com
   - New Monitor → HTTP(s)
   - URL: `https://твой-url.onrender.com/healthz`
   - Interval: 5 minutes

2. **Render Alerts**
   - Render Dashboard → Web Service → Metrics
   - Alerts → New Alert
   - CPU Usage > 80% → Email notification

### 3. Добавь товары (30 минут)

1. **Через админ-бота**
   - Открой админ-бота
   - Команда `/admin`
   - Добавь товары через панель

2. **Или через базу данных**
   - Используй seed скрипты
   - Или добавь вручную через админку

### 4. Запусти маркетинг (1 час)

1. **Канал @normwear_shop**
   - Опубликуй приветственный пост
   - Добавь правила канала
   - Опубликуй первые товары

2. **Привлечение пользователей**
   - Поделись ссылкой на бота
   - Запусти розыгрыш
   - Создай промокод для новых клиентов

## Частые вопросы ❓

**Q: Render спит, что делать?**
A: Настрой UptimeRobot для пинга каждые 5 минут.

**Q: Бот не отвечает?**
A: Проверь логи в Render и переменные окружения.

**Q: Как добавить товары?**
A: Через админ-бота `/admin` или напрямую в базу.

**Q: Как настроить платежи?**
A: Сейчас используется СБП вручную. Для автоматизации нужно подключить Telegram Payments.

**Q: Сколько стоит?**
A: Render бесплатен первые 90 дней, потом PostgreSQL $7/месяц.
