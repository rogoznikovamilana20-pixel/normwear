# NORMWEAR — План развития

## Архитектура
- 1 процесс Render free: uvicorn + 2 бота + supplier daemon
- PostgreSQL (asyncpg), Redis (rate limit), aiogram 3.22
- Всё в одном контейнере, боты как asyncio.create_task

---

## 1. Уведомления о статусе заказа — P0, Средне

**Что:** Клиент получает сообщение при смене статуса (сборка → отправлен → в пути → доставлен)

**Модель:** `Order.status` уже есть. Добавить `Order.status_updated_at`

**Bot shop:**
- Добавить `/track ORDER_ID` — показать статус + историю

**Bot admin:**
- В карточке заказа кнопки: 📦 Собирается, 🚚 Отправлен, 🛵 В пути, ✅ Доставлен
- При нажатии — менять статус + отправлять уведомление клиенту

**Миграция:** добавить `status_history_json` в `orders`

---

## 2. Промокоды — P0, Легко

**Что:** Скидки по коду (WINTER10 = 10%, FRIEND500 = 500₽)

**Модель `PromoCode`:**
```
id, code (unique), discount_type (percent/fixed), discount_value,
min_order, max_uses, used_count, expires_at, active, created_at
```

**API:** `POST /api/promo/validate` → возвращает скидку

**Миниапп:** поле "Промокод" в форме checkout → валидация → итого с учётом скидки

**Bot admin:** `/promos` → список, `/addpromo CODE TYPE VALUE` → создать

---

## 3. Избранное — P0, Легко

**Что:** Сохранять товары в избранное

**Модель `Favorite`:**
```
id, user_telegram_id, product_id, created_at
```

**Bot shop:**
- Кнопка ❤️ на каждом товаре (callback `fav:{id}`)
- Кнопка «Избранное» в главном меню
- Список избранных с пагинацией

**Миниапп:**
- Иконка ❤️ на карточке товара
- Сохранять в localStorage + синхронизировать с API

**API:** `GET /api/favorites`, `POST /api/favorites/{id}`, `DELETE /api/favorites/{id}`

---

## 4. Продвинутая статистика — P0, Легко

**Что:** Выручка за период, топ товаров, конверсия

**Bot admin:**
- Кнопка «📊 Статистика» → подменю: Сегодня / Неделя / Месяц / Всё
- Каждая кнопка показывает: заказов, выручка, средний чек, топ-3 товара

**API:** `GET /api/stats?period=day|week|month|all`

---

## 5. Отзывы — P1, Средне

**Что:** Клиент оценивает товар после доставки

**Модель `Review`:**
```
id, user_telegram_id, product_id, order_id, rating (1-5),
text, created_at
```

**Bot shop:**
- После статуса «Доставлен» → кнопка «Оставить отзыв»
- Рейтинг кнопками ⭐⭐⭐⭐⭐ + текст

**Bot admin:**
- Кнопка «⭐ Отзывы» → список новых → модерация (опубликовать/скрыть)

**Миниапп:** показывать рейтинг на карточке товара

---

## 6. Трекинг доставки — P1, Средне

**Что:** Номер отслеживания + статусы Доставки

**Модель `Shipment`:**
```
id, order_id, carrier (cdek/boxberry/post), tracking_number,
status, updated_at
```

**Bot admin:**
- Кнопка «🚚 Отправить» → ввод трек-номера
- Автопроверка статуса через API Доставки (CDEK API)

**Bot shop:**
- Кнопка «🗺 Отследить» в карточке заказа

---

## 7. Брошенная корзина — P1, Средне

**Что:** Напоминание если товар в корзине > 1 часа

**Реализация:**
- `CartReminder` модель: `user_id, product_ids_json, created_at, reminded`
- При добавлении в корзину (API) → создавать запись
- Background задача (supplier_daemon) → проверять каждые 10 мин → отправлять напоминание

**Bot shop:** сообщение «Забыли что-то? 🛒 Товары ждут»

---

## 8. Реферальная система — P1, Средне

**Что:** Invite-ссылка, бонус за покупку друга

**Модель `Referral`:**
```
id, referrer_id, referred_id, referred_order_id,
bonus_amount, status (pending/paid), created_at
```

**Bot shop:**
- `/start REF123` → сохранить реферера
- Кнопка «Пригласить друга» → ссылка `t.me/norm_shop_bot?start=ref{user_id}`
- Баланс бонусов

**Bot admin:**
- Настройка размера бонуса (`/refbonus 500`)
- Список рефералов

---

## 9. Рассылка по сегментам — P1, Средне

**Что:** Целевая рассылка: покупатели / не покупали / бросили корзину

**Bot admin:**
- Кнопка «📢 Рассылка» → подменю:
  - 📢 Всем
  - 🛒 Покупателям
  - ❌ Не покупали
  - 🔄 Бросили корзину

**Реализация:**
- Сегменты через SQL-запросы к orders/customers
- Rate limit: 30 сообщений/секунду (Telegram limit)

---

## 10. Онлайн-оплата — P1, Сложно

**Что:** Оплата через ЮKassa / Telegram Pay

**Зависимости:** Требует ИП/ОГРН, подключение к ЮKassa

**Реализация:**
- Bot shop: кнопка «💳 Оплатить» → invoice (Telegram Pay API)
- Или редирект на ЮKassa
- Webhook → смена `payment_status`

**Этап:** Когда будет юрлицо + подключение к платёжке

---

## 11. Live-чат — P2, Сложно

**Что:** Ответ прямо в боте (без пересылки)

**Реализация:**
- Бот shop: состояние «chat_mode» → все сообщения пересылаются
- Бот admin: реплаем на пересланное → ответ клиенту
- История чата в БД

**Уже сделано** (пересылка через SupportTicket). Live-чат = то же самое +:
- Сохранение истории
- Кнопка «Закрыть чат»
- Авто-ответы (FAQ)

---

## 12. Экспорт заказов CSV — P2, Легко

**Что:** Скачать заказы в CSV

**Bot admin:** кнопка «📥 Экспорт CSV» → формирует файл → отправляет

**API:** `GET /api/orders/export?from=2026-01-01&to=2026-12-31`

---

## 13. Пункты выдачи — P2, Средне

**Что:** Список точек на карте

**Модель `PickupPoint`:**
```
id, name, address, lat, lon, work_hours, active
```

**Bot admin:** CRUD пунктов через кнопки

**Миниапп:** список точек + карта (Yandex Maps API или iframe)
