# NORMWEAR — телеграм-магазин (дропшиппинг стритвира)

Стек: Python 3.12, aiogram 3.22 (long polling), FastAPI + uvicorn, SQLAlchemy 2 (async), SQLite (dev) / PostgreSQL (prod), фото-библиотека на Яндекс.Диске.

## Состав
- `@norm_shop_bot` — шоп-бот: каталог по брендам, корзина, оформление заказа, бонусы (1% кэшбэк, до 30% оплатой), рефералка (+100 за первый заказ друга), поддержка.
- `@normal_admin_bot` — админ-бот: модерация пересланных постов поставщика `@optobaza`, публикация в канал `@normwear_shop`, управление заказами и трек-номерами, промокоды, статистика, ответы клиентам.
- Веб-мини-апп (`/`) + REST API (`/api/*`), раздаёт FastAPI.

## Быстрый старт (Windows)
1. Убедитесь, что `.env` заполнен (см. `.env.example`; `DATABASE_URL=sqlite+aiosqlite:///C:/Users/andre/Projects/tg-bot/normwear.db` для локальной работы).
2. Двойной клик `start.bat` (создаст venv, установит зависимости, запустит всё).
3. Проверка: `http://127.0.0.1:8000/healthz`.

Проверка без запуска ботов: `.venv\Scripts\python -m app.main --check`

## Сценарий работы продавца
1. **Заливка товара**: перешлите пост из `@optobaza` в `@normal_admin_bot`. Бот распарсит цену/размеры/бренд, добавит фото с диска по бренду и покажет карточку: «✅ Опубликовать» → пост в канале; «✏️ Цена» — изменить; «🔄 Режим фото» — фото поставщика/Яндекс.Диск; «❌ Отклонить».
2. **Заказы**: `/orders` или кнопка из уведомления. Двигайте статус: Ждёт поступления → К оплате → Отправлен (ввести трек) → Доставлен → Завершён. Клиент получает уведомления автоматически.
3. **Поддержка**: сообщение клиента приходит в админ-бот, кнопка «💬 Ответить» — режим ответа.
4. **Промокоды**: `/promo CODE PERCENT [MIN_ORDER] [MAX_USES]`.

## Наценка
`retail = закупка × (1 + DEFAULT_MARGIN_PCT/100)` с округлением до 50 ₽ (`app/services/pricing.py`). По умолчанию 35%.

## Деплой (Render)
1. Залейте проект в GitHub (без `.env`!).
2. Render → New → из репозитория (использует `render.yaml`), создаст БД и сервис.
3. Впишите секреты (токены ботов, `SHOP_CHANNEL_ID`, `ADMIN_TELEGRAM_IDS`) в переменные окружения.

## Важно
- Секреты только в `.env` / переменных окружения. При утечке — ротация через @BotFather.
- `logs/app.log` — журнал работы. `normwear.db` — локальная база.
