# Мониторинг и бэкапы NORMWEAR

## Мониторинг

### 1. Health Check Endpoint
Проект уже имеет `/healthz` endpoint который возвращает `{"ok":true}`. Используется для:
- Render health checks
- UptimeRobot пингов
- Ручных проверок статуса

### 2. Логирование
Логи автоматически пишутся в:
- `logs/app.log` (локально)
- Render Logs (в облаке)

Уровни логирования:
- `INFO` - нормальная работа
- `WARNING` - некритичные проблемы
- `ERROR` - ошибки требующие внимания

### 3. Ключевые метрики для мониторинга

#### Web API
- Response time < 500ms
- Uptime > 99%
- Error rate < 1%

#### Telegram боты
- Боты онлайн (polling)
- Ответы на команды < 2s
- Ошибки API Telegram

#### База данных
- PostgreSQL соединения активны
- Query time < 100ms
- Нет deadlock'ов

### 4. Настройка оповещений

#### Render Alerts (бесплатно)
1. Render Dashboard → Web Service → **Metrics**
2. **Alerts** → **New Alert**
3. Настрой:
   - Metric: CPU Usage > 80%
   - Duration: 5 minutes
   - Notification: Email

#### UptimeRobot Alerts
1. UptimeRobot → Ваш Monitor → **Edit**
2. **Alert Contacts** → добавь email/Telegram
3. Приダウне - получишь уведомление мгновенно

## Бэкапы

### 1. Автоматические бэкапы (Render)

#### PostgreSQL
Render автоматически создаёт ежедневные бэкапы PostgreSQL:
- Хранятся 7 дней
- Бесплатно в первые 90 дней
- Потом $7/месяц за PostgreSQL

Проверка бэкапов:
1. Render Dashboard → Databases → `normwear-db`
2. Вкладка **Backups**
3. Видишь список бэкапов с датами

#### Файловые данные
Рекомендуется использовать внешнее хранилище для важных файлов:
- Фото товаров: Яндекс.Диск (уже настроено)
- Статические файлы: Git репозиторий

### 2. Ручные бэкапы

#### Экспорт PostgreSQL
```bash
# Через Render CLI
renderctl postgres dump normwear-db > backup_$(date +%Y%m%d).sql

# Или через psql
pg_dump $DATABASE_URL > backup_$(date +%Y%m%d).sql
```

#### Бэкап SQLite (локально)
```bash
# Для локальной разработки
copy normwear.db backups\normwear_$(date +%Y%m%d).db
```

#### Бэкап конфигурации
```bash
# Сохранить .env (без секретов!)
copy .env.example backups\.env.example_$(date +%Y%m%d)
```

### 3. Восстановление из бэкапа

#### PostgreSQL (Render)
1. Render Dashboard → Databases → `normwear-db`
2. Выбери бэкап из списка
3. Нажми **Restore**
4. Подтверди восстановление

#### SQLite (локально)
```bash
# Восстановление из бэкапа
copy backups\normwear_20260918.db normwear.db
```

## Инциденты

### Что делать при дауне

1. **Проверить статус**
   - UptimeRobot: красный?
   - Render Logs: ошибки?
   - Боты: не отвечают?

2. **Диагностика**
   - Render Dashboard → Web Service → **Suspended**?
   - Превышен лимит бесплатного тарифа?
   - Ошибка в коде (последний деплой)?

3. **Быстрое восстановление**
   - Если Suspended: Manual Deploy
   - Если ошибка кода: откатить коммит
   - Если превышен лимит: ждать нового месяца или перейти на платный тариф

4. **Связь с пользователями**
   - Написать в канал @normwear_shop о проблеме
   - Объяснить причину и время восстановления

### Критические ошибки
- База данных недоступна > 1 час
- Боты не отвечают > 30 минут
- Потеря данных (заказов, пользователей)

В этих случаях:
1. Немедленно восстановить из последнего бэкапа
2. Связаться с поддержкой Render
3. Проанализировать логи для предотвращения повторения

## Безопасность бэкапов

### Правила
- ✅ Бэкапы хранить в разных местах (Render + локально)
- ✅ Шифровать чувствительные данные
- ✅ Регулярно тестировать восстановление
- ❌ Не коммитить `.env` и секреты в Git
- ❌ Не хранить бэкапы на том же сервере

### Ротация бэкапов
- Ежедневные: хранить 7 дней
- Еженедельные: хранить 4 недели
- Ежемесячные: хранить 12 месяцев

## Мониторинг с помощью Telegram бота

Можно добавить команды для мониторинга в админ-бот:

### Добавить в `app/bots/admin.py`
```python
@router.message(Command("health"))
async def cmd_health(message: Message):
    """Проверка здоровья системы"""
    try:
        # Проверка БД
        async with SessionMaker() as s:
            await s.execute(select(func.count()).select_from(User))
        
        # Проверка ботов
        shop_status = "✅" if notify.shop_bot else "❌"
        admin_status = "✅" if notify.admin_bot else "❌"
        
        await message.answer(
            f"🏥 <b>Статус системы</b>\n\n"
            f"🗄 База данных: ✅\n"
            f"🤖 Shop бот: {shop_status}\n"
            f"🔧 Admin бот: {admin_status}\n"
            f"🌐 Web API: ✅"
        )
    except Exception as e:
        await message.answer(f"❌ Ошибка: {str(e)}")
```
